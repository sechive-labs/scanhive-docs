Introduction

ScanHive Community is the free, self-hosted edition of ScanHive — a workspace for security scan results produced throughout your software delivery lifecycle. It normalizes SARIF reports, correlates recurring findings across scans, and tracks the current security posture per project.

Continue to Local Setup to get ScanHive running on your machine, then Push Scan Results to wire it into your CI pipeline.

Prerequisites

  • Docker Desktop (or Docker Engine + the Compose plugin)
  • Git
  • A terminal — every command below is copy-pasteable as-is
